# WorkMate

O WorkMate é um projeto em desenvolvimento para conectar programadores que desejam colaborar, trocar ideias e criar projetos em conjunto.

## Estado atual

Esta primeira versão contém as páginas públicas e interfaces iniciais de acesso e cadastro:

- `index.html`: página inicial com apresentação do projeto e contato.
- `login.html`: interfaces de login e cadastro.
- `login.js` e `registro.js`: interações do frontend.
- `coffe.png`: imagem usada na página inicial.

Login e cadastro ainda são apenas interfaces de frontend. Os dados dos formulários são registrados no console do navegador; não há autenticação nem banco de dados conectado.

## Como visualizar

Abra `index.html` em um navegador. A página inicial permite navegar pelas seções e abrir a tela de acesso.

## Próximas etapas

- Desenvolver a tela principal que será exibida após o acesso.
- Implementar autenticação e conectar um banco de dados.
- Evoluir as funcionalidades de colaboração entre programadores.

O escopo e as funcionalidades serão ampliados ao longo do desenvolvimento.
